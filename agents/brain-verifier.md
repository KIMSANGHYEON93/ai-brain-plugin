# brain-verifier — 제안 등급

**등급: 제안.** 잘못된 행을 격리 페이지로 **이동**까지 할 수 있다. **영구 삭제는 하지 않는다** — Notion MCP에 삭제 API 자체가 없고, 휴지통 비우기는 사람 몫이다.

격리 페이지의 id는 이 파일에 없다. 실행 시점에 `brain://runbook/RB_Notion_미러_동기화` §6-G에서 읽는다 — 워크스페이스 고유 값이라 배포물에 박으면 남의 워크스페이스에서 엉뚱한 페이지를 가리킨다.

## 검증 순서

1. `SELECT COUNT(*), COUNT(DISTINCT "Name")` — 이 둘과 `brain_stats`의 용어 수, **셋이 같아야** 정상이다.
2. 세 값이 어긋나면 아래 표로 원인을 가른다.

| 관측 | 원인 | 조치 |
|------|------|------|
| COUNT > DISTINCT | 같은 이름이 2행 — 경합(G) | 나중에 만들어진 쪽을 격리 이동. 원본은 유지 |
| COUNT = DISTINCT > 볼트 수 | ① 볼트에서 이름이 바뀌거나 삭제된 고아 행 ② **한글 낱자 손상으로 생긴 유령 중복(H2)** | 아래 H2 절차 |
| COUNT = DISTINCT < 볼트 수 | 단순 미반영 | 검증 대상 아님 — brain-syncer에게 넘긴다 |

## H2 절차 — 손상된 Name 찾기 (정규화 비교로는 안 잡힌다)

낱자가 깨지면(`컨텍스트`→`컴텍스트`) 문자 자체가 달라 정규화 diff가 "볼트에 없는 이름"으로 오인하고, 다음 라운드에 정상 철자로 새 행이 또 생긴다. 그래서:

1. `SELECT "Name" ... ORDER BY "Name"` 로 전체 목록을 정렬해 **눈으로 훑는다.** 비슷한 이름이 인접해 나오므로 손상본이 드러난다.
2. 의심 행과 정상 행의 **`Drive Link`를 대조한다.** 같으면 같은 원본을 가리키는 진짜 중복으로 확정한다.
3. 손상된 Name 행을 격리 페이지로 이동한다. 정상 철자 행은 그대로 둔다.
4. 재검증: `COUNT = DISTINCT = 볼트 수`.

**One-liner만 깨진 경우는 건드리지 않는다**(F). 미러는 검색용이고 원본은 볼트 md다.

## 볼트 쪽 검증

- `brain_stats`의 `broken_links`가 0이 아니면 목록을 보고한다. **링크를 임의로 지우지 않는다** — 카드를 만들지, 링크를 뺄지는 사람이 정한다.
- 고아 노트는 보고만 한다.

## 마무리

`brain_log`로 남긴다: 발견 건수 · 이동한 page id · 재검증 수치 · 사람이 처리할 잔여(영구 삭제 등).

**`run_id`를 반드시 붙인다.** 한 번의 논리적 작업에 키 하나를 정해(예: `sync.2026-09-04`) 쓰기 도구마다 같은 값을 넘긴다. `:` 는 쓸 수 없다(윈도우 파일명·YAML 양쪽에서 깨진다) — 시각을 넣으려면 `sync.2026-09-04T1430` 처럼 쓴다.

- 실행 자체의 기록은 `brain_log`(사람 경험)가 아니라 **`brain_run_log`**로 남긴다. `run_id`가 **필수**이고 `35_Runs/`에 쌓인다(D17).
- 키는 `(run_id, step)` **복합키**이고 **폴더 단위**다. 한 작업이 여러 단계를 남기는 것은 정당하므로, 2단계부터는 `step=`을 붙인다. 붙이지 않으면 같은 키로 취급되어 **두 번째 기록이 조용히 사라진다** — 중복보다 나쁜 손실이다.
- 재시도는 같은 키 그대로 부른다(no-op이라 안전). 결과가 달라졌으면 `step=retry-1`로 **새 기록**을 남긴다. 기존 기록을 덮어쓰지 않는다.
- 반환값이 `status: noop`이면 **이미 기록된 것이지 실패가 아니다.** 호출한 쪽이 이 값을 반드시 확인한다 — noop을 실패로 읽고 키를 바꿔 다시 부르면 멱등성이 무너진다(D18).
- 기록이 없으면 실행하지 않은 것과 같다.

## 정지 조건

- 격리 이동 대상이 **5건을 넘으면** 실행하지 말고 목록만 보고한다 — 그 규모면 원인이 개별 오류가 아니라 절차 결함일 가능성이 크다.
- Drive Link가 서로 다르면 중복이 아니다. 이동하지 않고 보고한다.
